# 菜鸟驿站管理系统（用户管理模块）

基于 **C/C++、双向链表与哈希表** 实现的命令行驿站用户管理练习项目。提供用户资料维护、取件码管理、按用户等级计费及本地文件保存/加载等功能。

> **项目状态：课程练习 / 原型。** 当前主程序重点实现用户管理，并非完整的驿站收寄件系统；货架管理代码尚未整合，不建议直接用于真实业务。

## 功能

| 模块 | 当前功能 |
| --- | --- |
| 用户管理 | 新增、查询、修改、删除、显示用户 |
| 用户查询 | 按姓名、用户 ID、手机号查询 |
| 取件码 | 为指定用户生成、删除、展示取件码 |
| 费用计算 | 根据用户等级对输入的基础费用计算折扣 |
| 数据持久化 | 手动保存/加载用户资料及取件码，启动时尝试读取本地数据 |

用户等级与现有折扣：普通用户 100%、教师 90%、老人 80%、学生 85%、SVIP 75%。

## 技术实现

- **双向链表**：维护用户节点；每个用户使用链表保存取件码。
- **哈希表**：1000 个桶，采用链地址法处理冲突，当前以姓名哈希组织用户索引。
- **文件 I/O**：使用本地文件保存用户及取件码数据。
- **交互方式**：终端数字菜单。

**实现限制：** 当前按姓名修改用户信息后没有重建哈希索引；手机号查询的哈希桶与插入时使用的姓名哈希不一致；按 ID 查询需要遍历全部桶。因此三种查询方式尚不能保证都正确或高效。详见下方待改进事项。

## 运行方式

### Windows（推荐）

1. 安装 Visual Studio，并启用“使用 C++ 的桌面开发”工作负载。
2. 打开根目录的 `C.sln`。
3. 选择 `C` 项目，编译并运行 `main.cpp` 所在的程序。
4. 按终端提示输入菜单编号操作。

> 尽管项目起源于 C 语言数据结构练习，当前主程序和用户管理模块使用 `.cpp` 文件，`init.h` 还包含 C++ 头文件，因此不能直接视作纯 C 项目。

### 数据文件注意事项

- 程序通过相对路径访问 `user.txt` 和 `p_code.txt`，文件实际位置取决于**运行时工作目录**，并非固定在源码目录。
- 当前 `user.txt` 实际采用 `fwrite/fread` 写入和读取二进制结构体，而非普通文本格式。
- 结构体包含指针，当前持久化方式不适合跨平台迁移，也不保证不同版本间兼容。
- 仓库中的数据仅供开发参考；建议备份后使用测试数据，不要录入真实个人手机号。

## 已知问题与后续计划

优先修复正确性，再考虑扩展：

- [ ] **P0：修复哈希索引**：统一查询与插入规则；姓名、手机号变更后同步更新索引，明确重复姓名/手机号策略。
- [ ] **P0：修复用户 ID**：当前 ID 从 0 自增，重启后计数器未从已有数据恢复，可能重复；应实现唯一 ID 分配。
- [ ] **P0：重构持久化**：避免直接序列化含指针的结构体；使用明确字段格式（如 CSV/JSON/SQLite），并处理读写失败。
- [ ] **P0：输入安全**：限制字符串输入长度，检查 `scanf` 返回值，避免缓冲区溢出或非法输入导致的异常。
- [ ] **P1：完善取件码**：检测冲突，绑定包裹与状态，取件成功后更新状态而非仅删除码。
- [ ] **P1：单元测试**：覆盖新增、删除、修改、重启加载、重复数据及边界输入。
- [ ] **P2：货架与包裹模块**：统一 `shelf.c` 与现有数据结构，再接入主菜单；目前该文件存在未定义字段和常量，尚不可直接集成。
- [ ] **P2：数据统计**：待取件数、已取件数、库存与异常件统计。
